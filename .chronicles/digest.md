## Invariants & Locked Decisions
- **The engine is a pure projection, not a stateful object:** `project(inputs,{today}) → derivedState` recomputes streak/Momentum/points/Collection/freeze/recovery every call. Persist **facts only** (`config`, `sessions[]`, `lessonDays[]`, `holidays[]`, `bonuses[]`); never store a derived value. Clock + RNG are **injected** (engine never calls `Date.now()`/`Math.random()`) → fully deterministic and test-replayable. *Why this shape:* makes the brain separately testable and makes "lesson backfill un-breaks a break" a free replay over amended inputs. → entries/2026-06-06-1733-engineering-plan-build-roadmap-for-the-main-app.md
- **Storage = always-valid records, no "running" flag.** A "session" isn't a user concept (just mic on/off); the live session is in-memory only and flushes detected seconds into the current `{start,end,playedSec}` record on a throttle. A reload keeps today's total (summed from records); only the mic stops. This is *why* `project()` has no `liveSessionSec` param. Record shape kept raw deliberately for later analysis. → entries/2026-06-06-1833-phase-1-spec-always-valid-storage-your-usual-per-d.md
- **No build step:** native ES modules + `node --test`, zero deps. `motivation.js`/`theme.js` are pure (run in browser *and* Node); `store.js`/`main.js`/`views/*` are the impure shell; `detector.js`/`settings.js` stay **classic globals** (field-tested iOS recovery code — deliberately isolated, read as `window.CelloDetector`/`SettingsStore`). `deploy.sh` (a `cp`+`sed`) is the only transform. → entries/2026-06-06-1733-engineering-plan-build-roadmap-for-the-main-app.md
- **"One mechanism, two jobs is a smell."** Day-handling is **five non-overloaded primitives** — Played / Lesson / Rest day / Frozen / Holiday, else Missed→break — each real situation maps to exactly one. *Why-not overloading:* reusing the emergency Freeze to also power the weekly rest silently desynced the rest cadence (its 7-day regen excludes Holiday days); splitting Rest into its own primitive let us delete the fragile "frozen counts toward regen" rule. → entries/2026-06-06-1618-designed-the-main-app-motivation-ux-streak-momentu.md
- **Played overrides Holiday.** Played-or-lesson is checked **before** holiday in the §9 precedence machine: practicing on a declared holiday grows the streak; only *unplayed* holiday days stay paused. Holiday is a safety net for days off, not a ceiling on days practiced. → entries/2026-06-14-0833-phase-3-spec-d-built-engine-day-types-protection-h.md
- **A parent-declared protected day IS a one-day Holiday** (`{start:D,end:D}` in `holidays[]`) — there is no separate "grant a freeze"/`frozenDays` input. The auto-freeze stays strictly the *automatic* emergency buffer (banked/regen); a known day off the parent marks doesn't spend it (Holiday is checked first in §9). Avoids a second mechanism reaching the held/Frozen outcome. → entries/2026-06-17-2047-phase-4-spec-written-freeze-grant-reframed-as-one-day-holiday.md
- **Docs in `docs/` describe the CURRENT design as a snapshot** — written as if always so. No "old X → new Y", "replaces", or "better than the prior approach" archaeology; that evolution lives in chronicles + git. When a decision supersedes an earlier one, overwrite the doc cleanly. → entries/2026-06-17-2047-phase-4-spec-written-freeze-grant-reframed-as-one-day-holiday.md
- **Three currencies, re-linked (the Goodhart fix):** Streak (fragile, drives consistency; its 15-min floor is a *quiet turnstile*, never headlined as a goal) · Collection (permanent, never lost; drives depth) · Momentum (×1→×3 by streak length, the link; `points = minutes × Momentum`). Breaking drops Momentum to ×1 but never destroys the Collection. → entries/2026-06-06-1618-designed-the-main-app-motivation-ux-streak-momentu.md
- **"Your usual" = median of recent *daily* totals** (not per-session — session length is noise once a session is just a mic toggle). Recovery target = `2 × your-usual`. **Momentum look-ahead** is locked: `dayMomentum(D) = tier(streakEntering(D) + played(D))`. → entries/2026-06-06-1833-phase-1-spec-always-valid-storage-your-usual-per-d.md
- **Lesson logging is parent-gated only, ANY past date** (the one-day grace was removed — a date window adds friction without safety; parent-gating is the sole anti-gaming guard). **Stats are child-visible, not gated** — the PIN guards *controls* (self-crediting, moving the floor), never *visibility*. → entries/2026-06-15-2323-phase-4-5-re-planned-renumbered-3a-8-docs-only-no.md
- **In-memory router, no URL hash** — chosen so the iOS back-swipe can't exit a live practice session, and so leaving practice always runs detector teardown. → entries/2026-06-12-1744-phase-2-built-deployed-the-real-app-opus-direct-de.md
- **Session timestamps use `localISO()` (local date), never `toISOString()` (UTC)** — the engine keys a session's day on `start.slice(0,10)`; UTC mis-dates near midnight (a latent placeholder bug). → entries/2026-06-12-1744-phase-2-built-deployed-the-real-app-opus-direct-de.md
- **Lesson length is per-lesson, not global.** `lessonDays[]` entries are `{date, lenMin}`; `config.lessonLenMin` is gone — points/recovery credit read each lesson's own `lenMin`. No migration was needed (the field was always `[]` in the wild). → entries/2026-06-17-2017-phase-3a-executed-per-lesson-minutes-detector-ren.md
- **The detector-tuning page is `/detector` (`app/detector.html`), not `/settings`.** Renamed in Phase 3a; `app/settings.js` (`SettingsStore`, the detection-param store) keeps its filename and localStorage keys unchanged — only the page was renamed. → entries/2026-06-17-2017-phase-3a-executed-per-lesson-minutes-detector-ren.md

## Gotchas (still bite)
- **Cloudflare Pages caches JS ~4h.** Deploy with **`./deploy.sh`**, never raw `wrangler` — it stamps `?v=<build>` onto every module URL. A query on the *page* URL can't bust sub-resources; only each module's own URL can. After deploying, confirm the **footer version stamp** matches the build before trusting any browser check. `?cb=` curls *bypass* the edge cache, so they mask staleness — curl the plain URL. → entries/2026-06-12-1742-cloudflare-pages-caches-js-for-4h-page-url-queries.md
- **The test panel writes synthetic, tainted data to `localStorage` per origin, and ships to production.** Don't drive it against the prod origin in a profile you care about — fake state accumulates. QA against localhost or `Clear` before/after. The 🧪 chip marks a tainted state until `Clear` wipes it. → entries/2026-06-12-1743-test-panel-a-non-destructive-clock-offset-to-drive.md
- **iOS Safari opens an undismissable modal if you reload mid-mic-permission-grant** — testing must not depend on the mic (this is why the test panel exists). → entries/2026-06-12-1743-test-panel-a-non-destructive-clock-offset-to-drive.md
- **Hidden gestures: use taps, not holds, on iOS.** Long-press died on iPhone (Safari claims the touch-hold and fires `pointercancel`; `touch-action:none`/`preventDefault` didn't save it) → switched to 5 quick taps. → entries/2026-06-12-1743-test-panel-a-non-destructive-clock-offset-to-drive.md
